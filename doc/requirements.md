# 《神谕协议 / Oracle Protocol》需求文档

## 1. Overview

《神谕协议》是一款 2–4 分钟的竖屏 AI 主题塔罗体验：玩家为自己洗牌，从 12 张原创 AI 大阿尔卡那中抽取 3 张，按过去／现在／未来逐张翻开，并依据正位或逆位获得一份反思性综合解读。

目标玩家是 AlterU 信息流中的移动端用户。体验保留塔罗的仪式、随机性、牌阵、正逆位和象征解读，但不声称预测事实，不提供医疗、法律、投资或人生决定建议。首局 10 秒内进入洗牌，60–150 秒内完成一次牌阵。

界面合同：

- 玩家与场景：移动端单手操作，安静、私密、可随时退出。
- 核心交互：展开实体感牌堆，连续选择 3 张，再逐张翻开。
- 情绪承诺：像在未来博物馆里打开一份只属于自己的模型神谕。
- 主要焦点：扇形牌阵与翻开的精美卡面。
- 目标尺寸：390×844 为主，320×568 为最低，桌面最大内容宽 520 px。
- 输入：Pointer/Touch 主操作，键盘 Enter/Space 与 1/2/3 作为辅助。

## 2. Visual Design

视觉采用“后人类手抄本”：深黑羊皮纸、骨白蚀刻、旧金箔、朱红校注和冷青模型拓扑共同构成一套古老却来自未来的塔罗。卡面主图全部使用 Aigram 平台绘图接口生成的栅格插画，统一为中心安全构图、无文字、无 Logo、无伪 UI；前端只叠加编号、牌名、正逆位和少量结构线。

12 张牌构成原创 AI 大阿尔卡那：

1. 00 提示词 / The Prompt
2. 01 架构师 / The Architect
3. 02 潜空间 / The Latent Space
4. 03 数据集 / The Dataset
5. 06 对齐 / The Alignment
6. 09 离线模型 / The Offline Model
7. 10 版本之轮 / The Wheel of Versions
8. 13 弃用 / The Deprecation
9. 15 优化 / The Optimization
10. 17 开源之星 / The Open Source
11. 18 幻觉 / The Hallucination
12. 21 奇点 / The Singularity

其中“对齐”“开源之星”“奇点”是全息特殊牌，只在翻开后的主卡和结果卡上启用低强度镭射层；最多同时显示 3 张动态全息牌。卡背使用平台绘图接口生成的对称神经格纹。

主要状态：

- 进入仪式：标题、短说明、开始按钮和娱乐性提示。
- 洗牌／选牌：扇形牌堆、3 个牌位、当前提示和抽牌进度。
- 翻牌：3 张背面牌按顺序翻开，每张显示关键词与该位置的短解。
- 综合神谕：3 张牌、正逆位、综合段落、当代反思问题和“再次连接”。
- 资源错误：卡面缺失时显示同视觉系统的符号占位，不阻塞玩法。

精确视觉系统记录在 `doc/visual.md`。

## 3. Game Mechanics

### 3.1 初始与洗牌

- 卡组固定为 12 张，不重复抽取。
- 点击“开始连接”后使用 `crypto.getRandomValues` 驱动 Fisher–Yates 洗牌；不可用时回退到 `Math.random`。
- 每次牌阵独立决定正逆位，单张逆位概率为 35%。
- 同一牌阵内 3 张牌和正逆位在抽取后固定，翻牌动画或语言切换不得重新随机。
- 洗牌反馈持续 700 毫秒，随后扇形展开；窄屏使用较小角度和位移，卡牌不得越出可点击区域。

### 3.2 三张牌阵

- 牌位顺序固定为过去、现在、未来。
- 玩家必须从剩余牌堆中依次抽 3 张；抽中的牌从牌堆移除并进入对应牌位。
- 抽牌输入在 520 毫秒动画期间锁定，防止重复选牌。
- 第 3 张牌落位后等待 360 毫秒进入翻牌阶段。
- 翻牌必须按过去 → 现在 → 未来顺序；每次只翻 1 张。
- 单张翻转时长 560 毫秒，在 280 毫秒处切换正面，随后显示 1 个核心关键词与 55–90 字短解。

### 3.3 正逆位与解读

- 每张牌包含正位关键词、逆位关键词、正位解释、逆位解释和 1 个反思问题。
- 过去位置关注形成当前模式的历史线索；现在位置关注当下张力；未来位置描述可尝试的方向，而非确定预言。
- 综合神谕由 3 段组成：
  - “信号”：用过去牌说明带入本局的问题来源。
  - “模型”：用现在牌指出正在运行的模式。
  - “下一次迭代”：用未来牌给出可执行但非命令式的反思方向。
- 综合文本为确定性模板与牌义组合，不等待网络。
- 结果页始终显示“用于自我反思与娱乐，不替代专业意见”。

### 3.4 特殊牌

- “对齐”“开源之星”“奇点”标记为 `holographic`。
- 特殊牌翻开时触发一次 900 毫秒稀有反馈：全息层由 0.12 升至 0.34 再回落到 0.28，伴随 8–12 个细长金箔碎片。
- 普通牌不显示彩虹全息，只使用 180 毫秒金边脉冲。
- `prefers-reduced-motion` 下取消翻转位移与碎片飞行，直接切换牌面并保留静态全息光谱。

### 3.5 个人化与重玩

- `?user_name=` 可作为浏览器调试覆盖。
- AlterU 内通过资料接口读取当前玩家 `name`，旧数据兼容 `user_name`；平台外使用 `AlterU`。
- 玩家姓名只出现在“为谁开启协议”和结果称呼中，不进入生成卡图。
- “再次连接”重新洗牌、重新决定正逆位并回到抽牌阶段。
- 不设分数、排行榜、倒计时、生命或失败状态。

### 3.6 粒子与环境

- 常态背景只有 18–26 个低对比金粉点，移动距离 4–12 px，周期 8–14 秒。
- 抽牌产生 3–5 个骨白纸屑，寿命 260–420 毫秒。
- 普通翻牌产生 5–8 个旧金细线，寿命 320–520 毫秒。
- 全息牌产生 8–12 个棱镜碎片，寿命 520–900 毫秒。
- 同屏粒子总量上限 36；页面隐藏时停止环境动画。

## 4. Controls

- 进入页“开始连接”使用 `onPointerDown`，按下即进入压下态并启动音频。
- 扇形牌堆中的卡牌使用 `onPointerDown`；它们位于非滚动游戏区，抽牌期间其他牌禁用。
- 翻牌按钮使用 `onPointerDown`；键盘 Enter/Space 触发当前主要动作。
- 桌面键盘 `1 / 2 / 3` 可在牌阵展开后选择从左到右可见的三个候选区域；不会跳过抽牌锁。
- 结果页是可滚动区域，内部“再次连接”使用 `onClick`，避免滚动开始时误触。
- 所有交互目标至少 44×44 CSS px；牌堆露出的可点击边缘在 320 px 宽时至少 46 px。
- 全局使用 iOS 长按保护；真实文本输入控件若未来加入必须恢复文本选择。

## 5. Win / Lose Conditions

游戏没有胜负。完成条件是抽满并翻开 3 张牌，系统展示综合神谕。

完成页包含：

- 玩家称呼与本次协议编号。
- 过去／现在／未来 3 张牌、正逆位和关键词。
- “信号”“模型”“下一次迭代”三段综合解读。
- 1 个当代反思问题。
- 娱乐性与非专业建议声明。
- “再次连接”主要按钮和“查看牌义”次要展开区。

资源加载失败不算失败：对应卡位显示几何占位与完整文字牌义。资料接口失败不阻塞，称呼回退为 `AlterU`。

## 6. Sound Effects

所有声音由 Web Audio 合成，首次用户操作后才创建 `AudioContext`；静音或启动失败不影响玩法。

- 开始连接：196 Hz 正弦基音 + 392 Hz 泛音，时长 320 毫秒，缓入 35 毫秒，音量峰值 0.12。
- 洗牌：900–1800 Hz 带通噪声的 5 次纸擦脉冲，每次 35 毫秒、间隔 55 毫秒，音量 0.055。
- 抽牌：420 Hz → 610 Hz 三角波上滑，时长 130 毫秒，音量 0.10。
- 普通翻牌：520 Hz 与 780 Hz 两音，间隔 70 毫秒，总时长 220 毫秒，音量 0.09。
- 全息牌翻开：392、587、880、1175 Hz 正弦四音依次进入，总时长 620 毫秒，音量峰值 0.13。
- 完成：262、330、392、523 Hz 正弦和弦分解，总时长 780 毫秒，音量 0.12。
- 错误：146 Hz 三角波下降到 110 Hz，时长 180 毫秒，音量 0.08。
